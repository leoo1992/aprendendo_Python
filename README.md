# Aprendendo Python

Repositório de estudos introdutórios de Python, com exercícios e anotações em notebooks Jupyter. Material desenvolvido durante os estudos no SENAI.

## Stack
- Python 3
- Jupyter Notebook / Google Colab

## Como executar
Abra `aprendendoPython.ipynb` ou `fundamentosPython.ipynb` no Google Colab ou em um ambiente Jupyter com kernel Python 3.
